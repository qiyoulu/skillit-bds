# Skillit Kit BDS v1.5 — release notes
**Last updated:** 2026-10-24
**Status:** tagged `v1.5`. Follows v1.4 (`a55ae0a`, tag `v1.4`).
**Comparison baseline:** v1.4. A consumer on v1.3 reads the [v1.4 notes](./v1.4.md) first, then this file; the two together are the full change set since v1.3.

## Summary
Padding and spacing rules finished after the v1.4 tag: a 16px list card, a Text-0.75x padding of 6px / 12px with no exception, label and button spacing, and a larger `x-octagon` icon. Text weights step down 50 per tier from 700 (8×) to 400 (1×).

**Migration required:** Yes, for anything built on `--padding-0.75x` or the five changed text weights.

## Changed tokens
- `--padding-0.75x`: `0.25rem 0.5rem` (4px / 8px) to **`0.375rem 0.75rem` (6px / 12px)**. The compact exception is removed; every tier follows the 0.5× vertical / 1× horizontal ratio.

- Text weights, to the ramp 700 / 650 / 600 / 550 / 500 / 450 / 400 (8× down to 1×), bolded = base + 200:
  - `--text-4x-weight`: 650 to **600**
  - `--text-2x-weight`: 550 to **500**
  - `--text-1x-weight`: 450 to **400**
  - `--text-3x-weight-bold`: 700 to **750**
  - `--text-1.5x-weight-bold`: 600 to **650**
  - Text-0.75x stays 550. Sizes, tracking and leading are unchanged.

## Added
- **List card** (`components/cards.md`): `--space-4` (16px) padding, and 16px between cards at every width, for cards that repeat in a grid or list, such as job listings. The column gap rule (`--space-gutter`) does not apply to list cards. Feature cards stay at `--space-8` (32px). One tier per grid.
- **Static tag** (`components/badges.md`): square (`0px`), Canvas or Plaster fill, Iron Text-0.75x at 600, `--space-1.5` / `--space-3` padding, no icon, never interactive. Hard ban 4, layout rule 7 and `cards.md` name static tags beside the other `0px` shapes.
- **Form label gap** (`components/forms.md`): label to input `--space-2` (8px); between field groups `--space-5` (20px).
- **Hover states** (`components/forms.md`, `checkboxes.md`, `links.md`, `tables.md`, `toast.md`, `navigation.md`, `footer.md`, `cards.md`, `states.md`; `rules/data-viz.md`). Inputs, textareas and selects: Plaster hover fill. Checkboxes: Traffic Cone hover stroke, and fill when checked; unchecked never takes a gray fill (2.2431:1 against the 3:1 floor). Links: `--color-link-hover` plus a 2px underline, 5.3511:1 on Canvas. Menu button, modal close and toast close: `--color-surface-hover` circle. Actionable table rows: the hover token of the row's own fill. Chart marks and map regions: 2px Iron outline, fill unchanged, pie slices excluded. Selected cards carry the checked indicator and do not change on hover. `states.md` indexes the rules.
- **Button spacing** (`components/buttons.md`): adjacent buttons `--space-4` (16px); `--space-2` (8px) for compact toolbars; never under 8px.

## Changed assets
- `assets/icons/x-octagon.svg`: octagon enlarged from 20px to 22px across in the 24px frame.

## Consumers
- **Regenerate tokens.** `--padding-0.75x` changes value. Squarespace `custom.css` has no rule using it.
- **Figma.** The Text-0.75x padding variable moves to 6 / 12. Five weight variables change as listed above.
- **Squarespace `custom.css`.** Update the tier weight map: 4× 600, 2× 500, 1× 400, 3× bold 750, 1.5× bold 650.
- **Webflow.** Text-4 600; Text-2, 2s, 2m 500; Text-1, 1m 400; Text-3 bold and 3sb 750; Text-15b and 15sb 650.
- **Rails.** Regenerate tokens; email and table styles follow the 1× weights (400, bolded 600).
- **Hover.** Add the rules above wherever those controls are built. Squarespace `custom.css` and Webflow need link hover (`--color-link-hover`), input and select hover fill, and checkbox hover. The coverage map takes the 2px Iron mark outline.
- **Job cards on Squarespace.** Build with `--space-4`. Existing quote and author blocks stay at 32px.

Deploying changes to consumers requires separate approval.
