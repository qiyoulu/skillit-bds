# Skillit Kit BDS v1.5 — release notes
**Last updated:** 2026-10-22
**Status:** draft. Not tagged. Follows v1.4 (`a55ae0a`, tag `v1.4`).
**Comparison baseline:** v1.4.

## Summary
Padding and spacing rules finished after the v1.4 tag: a 16px list card, a Text-0.75x padding of 6px / 12px with no exception, label and button spacing, and a larger `x-octagon` icon.

**Migration required:** Yes, for anything built on `--padding-0.75x`.

## Changed tokens
- `--padding-0.75x`: `0.25rem 0.5rem` (4px / 8px) to **`0.375rem 0.75rem` (6px / 12px)**. The compact exception is removed; every tier follows the 0.5× vertical / 1× horizontal ratio.

## Added
- **List card** (`components/cards.md`): `--space-4` (16px) padding, and 16px between cards at every width, for cards that repeat in a grid or list, such as job listings. The column gap rule (`--space-gutter`) does not apply to list cards. Feature cards stay at `--space-8` (32px). One tier per grid.
- **Static tag** (`components/badges.md`): square (`0px`), Canvas or Plaster fill, Iron Text-0.75x at 600, `--space-1.5` / `--space-3` padding, no icon, never interactive. Hard ban 4, layout rule 7 and `cards.md` name static tags beside the other `0px` shapes.
- **Form label gap** (`components/forms.md`): label to input `--space-2` (8px); between field groups `--space-5` (20px).
- **Button spacing** (`components/buttons.md`): adjacent buttons `--space-4` (16px); `--space-2` (8px) for compact toolbars; never under 8px.

## Changed assets
- `assets/icons/x-octagon.svg`: octagon enlarged from 20px to 22px across in the 24px frame.

## Corrected
- `LLM-INSTRUCTIONS.md` and `docs/design-reference.md` said v1.4 had no tag or Release. v1.4 is tagged and published.

## Consumers
- **Regenerate tokens.** `--padding-0.75x` changes value. Squarespace `custom.css` has no rule using it.
- **Figma.** The Text-0.75x padding variable moves to 6 / 12.
- **Job cards on Squarespace.** Build with `--space-4`. Existing quote and author blocks stay at 32px.

Deploying changes to consumers requires separate approval.
