# Skillit Kit BDS v1.9 — release notes
**Last updated:** 2026-11-11
**Status:** v1.9. Follows v1.8 (tag `v1.8`).
**Comparison baseline:** v1.8.

## Summary
The mobile back and forward bar gets labeled buttons so the Intercom launcher covers only part of Next. Search gets its own component: a pill field with the search button inside, as on the help center. Personal email signatures match the email client's default text size instead of the 16px email minimum.

**Migration required:** Yes, for the mobile back and forward bar:
- Replace the 40px icon-only circles with ( ← Back ) ( Next → ) pill buttons, each half the bar, on a Canvas bar.
- Keep Next in the right column on screens without Back.

The search field and signature exception describe what already ships on the help center and in the email signature template.

## Added
- **Search field** (`components/forms.md`): a Plaster pill on Canvas, 48px minimum height, 8px / 64px / 8px / 24px padding, Text-1x 400 Iron. The submit button is a 40px Traffic Cone circle inset 4px inside the right end, with a 24px Iron search icon and the accessible name "Search". The field keeps a visually hidden label; the placeholder says what is searched. Matches the help center (Webflow `.help-search.in-form` and `.search-submit`). Illustrations draw it at 2×.

## Changed rules
- **Back and forward sticky bar** (`components/navigation.md`): labeled pill buttons instead of icon-only circles. Canvas bar on the page gutter, 8px top and bottom plus the safe area, two equal columns with a 16px gap. Back is Plaster with its arrow at the far left edge; Next is Traffic Cone with its arrow at the far right edge. Text-1x semibold, `--padding-1x`, 40px minimum height. A 1px Iron top border appears only while content scrolls under the bar. A lone Next keeps its half-width right column so it never moves. The Intercom launcher overlaps the right end of Next on mobile; this is a stopgap until help has a mobile home that doesn't float over content.
- **Button icon placement** (`components/buttons.md`): Back in the sticky bar mirrors the non-hugging rule, arrow at the far left edge and label at the far right.
- **Input corners** (`components/forms.md`, `components/cards.md`, `LLM-INSTRUCTIONS.md`, `docs/design-reference.md`): inputs stay 0px, except the search field, which is a pill. The 4px trailing-icon hug rule now covers clear and calendar icons, not search.
- **Email minimum size** (`components/email.md`, `LLM-INSTRUCTIONS.md`, `HUMAN-INSTRUCTIONS.md`, `docs/design-reference.md`): personal email signatures are exempt from the 16px minimum. They match the client's default body text (13px in Gmail) so they read as part of the message, and are set no smaller than that default.

## Consumers
- **Rails (mobile flows):** rebuild the back and forward bar to the new spec on every flow that uses it, including worker onboarding.
- **Webflow (help center):** no change; the search field spec is taken from it.
- **Squarespace:** use the search field spec for any site search, and its 2× drawing for illustrations.
- **Email:** `email/signature.html` already follows the signature exception.
