# Skillit Kit BDS v1.7 — release notes
**Last updated:** 2026-10-30
**Status:** draft, not tagged. Follows v1.6 (tag `v1.6`).
**Comparison baseline:** v1.6.

## Summary
Three opt-in accessible color variants give AA-passing options for the brand colors that fail on light surfaces. The separation rule gains a decision order. The retired-color list gains two near-miss values. No existing token value or default usage changes.

**Migration required:** No. Brand colors stay the default. The variants are opt-in only and never defaults: do not swap them into themes, templates, global styles or component defaults; apply them per instance only where a context requires AA.

## Added
- **Accessible variants** (`tokens/tokens.json5`, `tokens/generated/tokens.css`, `tokens/generated/tailwind-theme.js`, `tokens/docs/color.md`):
  - `--color-primary-accessible` `#B6500D` (Traffic Cone): 4.5289:1 on Canvas, 5.0697:1 on Plaster.
  - `--color-warning-accessible` `#986401` (Hard Hat): 4.5113:1 on Canvas, 5.0500:1 on Plaster.
  - `--color-link-accessible` `#0077A0` (Painter's Tape): 4.5244:1 on Canvas, 5.0647:1 on Plaster.
  For text, icons and focus rings on Canvas or Plaster. Never fills, buttons, chart data, print, or on Iron. Toolbox and Bottle Glass already pass and get no variant.
- **Separation order** (`rules/layout.md`): space, then alignment and type hierarchy, then Plaster-on-Canvas contrast, then a Plaster card. The no-lines rule is unchanged.
- **Near-miss colors** (`tokens/docs/color.md`): `#233136` (Iron) and `#007EA8` (Painter's Tape) are listed as values to correct.

## Changed rules
- **Contrast exceptions** (`tokens/docs/color.md`, `rules/accessibility.md`, `LLM-INSTRUCTIONS.md`): where AA is required, use the accessible variant or Iron. Previously Iron was the only option.
