# Skillit Kit BDS v1.7 — release notes
**Last updated:** 2026-11-02
**Status:** tagged `v1.7`. Follows v1.6 (tag `v1.6`). The November 2026 brand guide PDF is published as v1.7 to stay in sync with this repo.
**Comparison baseline:** v1.6.

## Summary
Three opt-in accessible color variants give AA-passing options for the brand colors that fail on light surfaces. The separation rule gains a decision order. Text-0.75x now uses weights 400 and 600 with no tracking. Static tags become plain text. Seven icons join the set, for 100 in total. Print values, logo rules, the mission and stock guidance now match the brand guide.

**Migration required:** Yes, for consumers that copy tokens or styles:
- Replace hardcoded Text-0.75x values (weight 550, tracking 0.04em) with the current tokens.
- Remove fill and padding from existing static tags.
- Use Pantone 433 and the new CMYK values for Iron, and the new CMYK values for Canvas and Toolbox, in new print work.

The accessible variants need no migration. Brand colors stay the default. The variants are opt-in only and never defaults: do not swap them into themes, templates, global styles or component defaults; apply them per context only where a context requires AA.

## Added
- **Accessible variants** (`tokens/tokens.json5`, `tokens/generated/tokens.css`, `tokens/generated/tailwind-theme.js`, `tokens/docs/color.md`):
  - `--color-primary-accessible` `#B6500D` (Traffic Cone): 4.5289:1 on Canvas, 5.0697:1 on Plaster.
  - `--color-warning-accessible` `#986401` (Hard Hat): 4.5113:1 on Canvas, 5.0500:1 on Plaster.
  - `--color-link-accessible` `#0077A0` (Painter's Tape): 4.5244:1 on Canvas, 5.0647:1 on Plaster.
  - `--color-link-accessible-hover` (`color-mix` of the above with 10% black): 5.6626:1 on Canvas, 6.3388:1 on Plaster.
  Default and accessible tokens are sets: a context uses one or the other, never a mix.
  For text, icons and focus rings on Canvas or Plaster. Never fills, buttons, chart data, print, or on Iron. Toolbox and Bottle Glass already pass and get no variant.
- **Separation order** (`rules/layout.md`): space, then alignment and type hierarchy, then Plaster-on-Canvas contrast, then a Plaster card. The no-lines rule is unchanged.
- **Near-miss colors** (`tokens/docs/color.md`): `#233136` (Iron) and `#007EA8` (Painter's Tape) are listed as values to correct.
- **Icons** (`assets/icons/`): `bell`, `bell-alert`, `bell-slash`, `arrow-uturn-up`, `arrow-uturn-down`, `arrow-uturn-left` and `arrow-uturn-right`.
- **Text-0.75x tokens** (`tokens/tokens.json5`, `tokens/generated/tokens.css`, `tokens/docs/typography.md`): `--text-0.75x-weight-bold` (600) and `--text-0.75x-print` (9pt). The tier is now in the main scale table.

## Changed rules
- **Text-0.75x** (`tokens/`, `components/validation.md`, `components/metadata.md`, `rules/data-viz.md`): weight 550 becomes 400, bolded 600. Tracking 0.04em becomes 0. Metadata, references, footnotes and captions use 400. Static tags, other labels and validation messages use 600. Byline names use 600, and affiliation and other details use 400.
- **Static tags** (`components/badges.md`): plain text with no container. A Text-1x Traffic Cone highlight tag is allowed on Plaster as a documented contrast exception. Status tags remain icon and label, with no tints or dots.
- **Print values** (`tokens/`, `docs/design-reference.md`): Iron is Pantone 433, CMYK 35/13/0/80. Canvas is CMYK 0/2/4/3. Toolbox is CMYK 2/100/85/5.
- **Logo** (`tokens/docs/logo.md`, `LLM-INSTRUCTIONS.md`, `HUMAN-INSTRUCTIONS.md`, `docs/design-reference.md`): Plaster on Iron is allowed in the footer band only. A single-color outline is allowed for embroidery and engraving only.
- **Mission** (`brand/narrative.md`, `voice/brand-voice.md`): the mission is “Give everyone access to the world’s best construction opportunities.” “Technology should make humans more essential, not more expendable” is the anchor.
- **Stock photography** (`LLM-INSTRUCTIONS.md`, `HUMAN-INSTRUCTIONS.md`, `brand/strategy.md`, `docs/design-reference.md`, `voice/brand-voice.md`): Adobe Stock is preferred rather than required. Generative AI stays excluded.
- **Icon paint** (`scripts/`, `components/icons.md`, `components/checkboxes.md`): icon checks use canonical Iron `#232F36`. `#233136` is legacy. `checkbox-unchecked` and `radio-unchecked` join the approved exports, for 14 in total.
- **Contrast exceptions** (`tokens/docs/color.md`, `rules/accessibility.md`, `LLM-INSTRUCTIONS.md`): where AA is required, use the accessible variant or Iron. Previously Iron was the only option.
