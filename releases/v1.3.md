# Skillit Kit BDS v1.3 — release notes
**Last updated:** 2026-10-14
**Status:** v1.3 source release. No Git tag or GitHub Release created.
**Comparison baseline:** v1.2 (`26ef3b0`). Covers every change since.

## Summary
v1.3 adds the rules that came out of building the enterprise landing-page graphics: how tables separate rows, what replaces a divider line, how bars take corners, how to pick type weight in an exported graphic, and how maps draw supply, demand, and the connections between them. It also adds a component index so new files can't go unlisted. No tokens, icons, or colors changed.

**Migration required:** None. Every change is additive or narrows an ambiguous rule. The one rule that reads differently is the bar-corner rule in `rules/data-viz.md`; see below.

## New
- [`components/tables.md`](../components/tables.md): tables alternate Canvas and Plaster rows, starting with Canvas. No divider rules, gridlines, or borders. The whole table clips to a 16px radius; rows stay square. Labels flush left, values flush right in the bolded weight, tabular numerals. Includes a CSS example.
- [`components/README.md`](../components/README.md): an index of all 18 components with a one-line description each, plus links to the five shared rule files.
- A check in `scripts/test-instructions.py` that fails if a component file is missing from the index, or if the index lists a file that does not exist. Confirmed to fail both ways on a copy of the repo.
- A **product graphics** section in [`rules/photography.md`](../rules/photography.md): drawn UI and diagrams on one Plaster card with 16px corners and a 48px margin at an 800 x 600 tile, 4:3 exported at 2x, Iron and Plaster plus one accent, real figures from the copy.

## Changed rules
- **Separation (`rules/layout.md`).** The no-layout-lines rule now says what to use instead: give each group its own Plaster card on Canvas, or alternate row fills in a table. Lines are for data only.
- **Bar corners (`rules/data-viz.md`).** The old rule said all bars are `0px`. It now splits in two:
  - Axis-based bars (bar, grouped, histogram, stacked) stay square.
  - Comparison and progress bars that read as a share of a track, with no axis, use a pill end. The track is a Canvas pill and the fill is clipped to it, so the right end stays at the true length. Every bar carries its value as a label.
  - Existing charts are unaffected. Only graphics that already used a track-and-fill bar may choose the pill.
- **Maps (`rules/data-viz.md`).** Demand (Traffic Cone) draws first and supply (Painter's Tape) above it. A connection arc paints as a gradient from the supply color to the demand color in the direction of flow, 4px at its lightest, round caps. Routes with too few people to protect identity are not drawn.
- **Icons and the logo mark (`rules/iconography.md`).** Scale only in whole multiples of the source canvas (24, 48, 72, 96), so each 2px block lands on whole pixels. Sizes such as 38px or 44px blur the geometry.
- **Typography (`tokens/docs/typography.md`).**
  - In an exported graphic, assign the tier and weight by the size the text is displayed, not the size it is drawn. Text drawn at 32px and shown at 16px takes the Text-1x weights.
  - A note on verifying the variable font: some renderers snap weights when the font is installed by name, so 450 draws as 500. Load the file with `@font-face` and `font-weight: 100 900`, and confirm 450, 550, and 650 measure at different widths.

## Not changed
- `tokens/tokens.json5` and the generated tokens. Nothing here adds a token, so nothing needs regenerating.
- The 90 canonical icons and the legacy archive.
- Colors, type tiers, spacing, and radii.

## Consumers
