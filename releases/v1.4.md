# Skillit Kit BDS v1.4 — release notes
**Last updated:** 2026-10-22
**Status:** v1.4 source release. No Git tag or GitHub Release created.
**Comparison baseline:** v1.3 (`d2b12d0`). Covers every change since.

## Summary
v1.4 fixes the page frame: header height, logo size, card padding, side margins, and top and bottom padding now follow one contract from mobile to desktop. It also fixes a gap in v1.3: between 1024px and 1199px the 1200px content block had no side margin and ran to the screen edge. The navigation now collapses to a menu button until 1280px, where the full bar fits. The mega menu panel, marketing hit area, and quote-card changes made after v1.3 ship in this release.

**Migration required:** Yes. Two tokens change value, the column gap changes from 24px to a 16–32px ramp, and several defaults change. See Consumers.

## Changed tokens
- `--logo-height`: 24px to **32px**. Lockup and mark use the same height.
- `--space-128`: `clamp(48px, 10vw, 128px)` to **`clamp(2rem, calc(12.5vw - 2rem), 8rem)`**. Anchored at 64px for 768px and 128px for 1280px, floored at 32px, in `rem` so it follows the user's font-size setting. Up to 768px, top and bottom padding is exactly twice `--space-gutter`: 32px against 16px on mobile, 64px against 32px at 768px, ramping together from 512px. At 1280px and above the value is unchanged at 128px.
- Descriptions for `max-width-content`, `max-width-app`, `md`, `lg`, and `xl` updated to match.

## Changed rules
- **Header.** A 64px row on Canvas, no texture band. The 32px logo sits with 16px above and below. The boot-tread band is removed from the navigation (`components/navigation.md`, `rules/layout.md`, `tokens/docs/logo.md`, `docs/design-reference.md`). Texture in document headers and footers is unchanged.
- **Content width.** Side padding is `--space-gutter`: 32px from 768px, 16px to 512px and a ramp between, shared by header, body, and footer, and never drops to zero. The container is `max-width: calc(var(--max-width-content) + 2 * var(--space-gutter))`, so the 1200px width is reached at 1264px and centered above it. v1.3 set zero side padding from 1024px.
- **Tablet grid.** 768–1023px uses two columns (336px each at 768px with the 32px gutter, never below `--column-min-width`) instead of one.
- **Cards.** 32px padding at every size. Desktop and tablet were 64px; mobile was already 32px.
- **Navigation breakpoint.** The menu button, mark, and stacked footer now apply below 1280px (`xl`), not 1023px. The lockup is about 172px wide at 32px high, and the full bar needs more room than 960px reliably gives. The logo rule moves with it: mark only in the header and footer below 1280px, not below 768px.
- **Mobile menu layout.** Links are top-aligned and flush-left as 48px Text-1.5x rows. The primary button and secondary trigger sit in a bar pinned to the foot, with empty space between. The position of a language picker is not yet specified.
- **Form inputs.** Editable inputs use the `--padding-1x` pair (8px 16px) with `min-height: var(--touch-target-min)` and the Text-1x leading, instead of the 12px 16px field exception.
- **Section padding.** Minimum is 32px on mobile and 64px from 768px, matching `--space-128`. `rules/layout.md` said 40px on mobile while `tokens/docs/spacing.md` said 32px; both now say 32px.

## Deprecated and added
- **Deprecated:** the `--space-*x` aliases (`--space-0.25x` through `--space-8x`). Use the numeric token: `--space-2x` is `--space-8`. No consumer uses them; they are removed in a later release.
- **Added:** `--space-page`, an alias of `--space-128` named for its role. `--space-128` stays.
- **Added:** `--space-gutter`, one value for the page side margin and the column gap, a single `clamp(1rem, calc(6.25vw - 1rem), 2rem)`: 16px to 512px, ramping to 32px at 768px. Header, body, footer and grids share it, so the margin cannot drift between them again. **The column gap changes from 24px to 16px (mobile), ramping to 32px (768px and up).** The container formula in `rules/layout.md`, `components/navigation.md` and `components/footer.md` now uses it.
- **Removed:** `--space-256`. No consumer called it; Rails, Squarespace and the Contentful sample only copy the definition or show it in docs.

## Not changed
- Colors, type tiers, radii, and the 90 canonical icons.
- The touch-target minimum (`--touch-target-min`, 40px). Apple and Material recommend 44–48px; this release leaves the BDS value as it was.
- The email card padding (64px) in `components/email.md`.

## Consumers
- **Regenerate tokens.** `tokens/generated/tokens.css` carries the new `--logo-height`, `--space-128`, `--space-page` and `--space-gutter`, and no longer carries `--space-256`. The `--space-*x` aliases stay, deprecated. `tailwind-theme.js` adds the `gutter` and `page` keys (`px-gutter`).
- **Column gap.** Anything laid out with a 24px gap (`--space-6`) between columns moves to `--space-gutter`. Squarespace's `custom.css` and the two testimonial blocks in `workspace/squarespace` already carry the new tokens; Rails has three `--space-128` lines to switch if it adopts the alias.
- **Squarespace and Rails:** cards, the header, and the nav breakpoint need to follow. Figma frames should be built at 375, 768, and 1280px. No consumer code is changed by this release.
