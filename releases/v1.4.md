# Skillit Kit BDS v1.4 — release notes
**Last updated:** 2026-10-20
**Status:** v1.4 source release. No Git tag or GitHub Release created.
**Comparison baseline:** v1.3 (`d2b12d0`). Covers every change since.

## Summary
v1.4 fixes the page frame: header height, logo size, card padding, side margins, and top and bottom padding now follow one contract from mobile to desktop. It also fixes a gap in v1.3: between 1024px and 1199px the 1200px content block had no side margin and ran to the screen edge. The navigation now collapses to a menu button until 1280px, where the full bar fits. The mega menu panel, marketing hit area, and quote-card changes made after v1.3 ship in this release.

**Migration required:** Yes. Two tokens change value and several defaults change. See Consumers.

## Changed tokens
- `--logo-height`: 24px to **32px**. Lockup and mark use the same height.
- `--space-128`: `clamp(48px, 10vw, 128px)` to **`clamp(2rem, calc(12.5vw - 2rem), 8rem)`**. Anchored at 64px for 768px and 128px for 1280px, floored at 32px, in `rem` so it follows the user's font-size setting. Top and bottom padding is now twice the side margin: 32px against 16px on mobile, 64px against 32px at 768px. Between 512px and 767px the ratio drifts up to 4:1 and resets at 768px. At 1280px and above the value is unchanged at 128px.
- Descriptions for `max-width-content`, `max-width-app`, `md`, `lg`, and `xl` updated to match.

## Changed rules
- **Header.** A 64px row on Canvas, no texture band. The 32px logo sits with 16px above and below. The boot-tread band is removed from the navigation (`components/navigation.md`, `rules/layout.md`, `tokens/docs/logo.md`, `docs/design-reference.md`). Texture in document headers and footers is unchanged.
- **Content width.** Side padding is 32px from 768px and 16px below, shared by header, body, and footer, and never drops to zero. The container is `max-width: calc(var(--max-width-content) + 2 * var(--space-8))`, so the 1200px width is reached at 1264px and centered above it. v1.3 set zero side padding from 1024px.
- **Tablet grid.** 768–1023px uses two columns (340px each at 768px with the 24px gutter, never below `--column-min-width`) instead of one.
- **Cards.** 32px padding at every size. Desktop and tablet were 64px; mobile was already 32px.
- **Navigation breakpoint.** The menu button, mark, and stacked footer now apply below 1280px (`xl`), not 1023px. The lockup is about 172px wide at 32px high, and the full bar needs more room than 960px reliably gives. The logo rule moves with it: mark only in the header and footer below 1280px, not below 768px.
- **Mobile menu layout.** Links are top-aligned and flush-left as 48px Text-1.5x rows. The primary button and secondary trigger sit in a bar pinned to the foot, with empty space between. The position of a language picker is not yet specified.
- **Form inputs.** Editable inputs use the `--padding-1x` pair (8px 16px) with `min-height: var(--touch-target-min)` and the Text-1x leading, instead of the 12px 16px field exception.
- **Section padding.** Minimum is 32px on mobile and 64px from 768px, matching `--space-128`.

## Added since v1.3
- **Mega menu panel** (`components/navigation.md`): trigger, panel, audience line, motion, behavior, and the mobile drill-in.
- **Marketing hit area** (`components/buttons.md`): the visible pill keeps its tier height; the hit area extends to 44px.
- **Squarespace** (`LLM-INSTRUCTIONS.md`): variant-to-tier button mapping, and a note to escape `clamp()` in LESS 2.7.
- **Quote cards** (`components/quote-cards.md`): Text-1.5x at every length, and one decorative opening mark on cards without a headshot.

## Added after the v1.4 commit
- **SKILLIT Hire lockup** (`assets/logo/lockup-hire-iron.svg`, with its 512px-high PNG): the mark, wordmark, and Hire together, documented in `tokens/docs/logo.md`. The source file was named `lockup-iron-hire.svg` and painted `#233136`; it is renamed to fit the variant naming and painted canonical Iron `#232F36`. On SKILLIT Hire pages the lockup is set 32px high and stays full at every width, mobile included, in the header and footer; the mark-only swap below 1280px does not apply there (Laura Zhen's direction). Recorded in `tokens/docs/logo.md`, `components/navigation.md`, `components/footer.md` and `LLM-INSTRUCTIONS.md`.

## Not changed
- Colors, type tiers, radii, and the 90 canonical icons.
- The touch-target minimum (`--touch-target-min`, 40px). Apple and Material recommend 44–48px; this release leaves the BDS value as it was.
- The email card padding (64px) in `components/email.md`.

## Consumers
- **Regenerate tokens.** `tokens/generated/tokens.css` carries the new `--logo-height` and `--space-128`.
- **Squarespace and Rails:** cards, the header, and the nav breakpoint need to follow. Figma frames should be built at 375, 768, and 1280px. No consumer code is changed by this release.
