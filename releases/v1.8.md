# Skillit Kit BDS v1.8 — release notes
**Last updated:** 2026-11-10
**Status:** v1.8. Follows v1.7 (tag `v1.7`).
**Comparison baseline:** v1.7.

## Summary
Static layouts get their own rules: display tiers from Text-12x to Text-48x, a presentation column chart, print type sizing, and a highlight treatment that replaces orange text. A second audience's main action gets an Iron primary button. Tables now always sit on a card, and comparison and progress bars are rounded at both ends. Every external communication carries the logo.

**Migration required:** Yes, for tables and comparison or progress bars:
- Put existing tables on a padded card, and stop clipping them to a rounded edge. Rows are square.
- Round comparison and progress bars at both ends.

The display tiers, chart spec, print guidance and highlight rule are additive. They apply to presentations, print, posters and PDFs only, never to websites, apps or email.

## Added
- **Iron primary button** (`components/buttons.md`): the main action for a second audience, beside or instead of the Traffic Cone primary. Plaster text on Iron; Plaster with Iron text on dark sections and photo heroes. Never for quiet actions such as Learn more or Cancel. Squarespace's Tertiary button maps to it.
- **Static display tiers** (`tokens/tokens.json5`, `tokens/generated/tokens.css`, `tokens/generated/tailwind-theme.js`, `tokens/docs/typography.md`, `docs/design-reference.md`): Text-12x (192px / 144pt), Text-16x (256px / 192pt), Text-24x (384px / 288pt), Text-32x (512px / 384pt) and Text-48x (768px / 576pt). Bold 700, bolded 900, 0.80 leading, −6% tracking. One per slide or page. Never for websites, apps or email.
- **Sizing print files** (`tokens/docs/typography.md`): points and pixels explained; hand-held print uses the pt column in a 72px-per-inch artboard; large format is sized by viewing distance (about 1 inch of letter height per 10 feet). Business cards use Text-0.75x print (9pt) with the name bolded. A 33 × 81 in banner reference is included.
- **Presentation column charts** (`rules/data-viz.md`, `docs/design-reference.md`): for slides and other at-a-glance graphics with 12 bars or fewer. Each bar sits in a Plaster column with 16px corners on Canvas; bars have 16px corners on all four sides, keep a 32px minimum height, and never truncate the scale. Iron bars with one Traffic Cone highlight. Labels inside the top of each column in Text-1.5x. Source line required.
- **Highlight in static layouts** (`rules/layout.md`, `tokens/docs/color.md`, `docs/design-reference.md`): to emphasize words or a key number in a presentation, print piece or PDF, use Iron text on a Traffic Cone block (4.5443:1, AA), not orange text. Once per slide or page.
- **Logo in external communications** (`tokens/docs/logo.md`, `docs/design-reference.md`, `LLM-INSTRUCTIONS.md`): anything that leaves Skillit carries the logo: decks, documents, PDFs, emails, social posts, press materials, print and event collateral. Use the lockup; use the mark alone only where the lockup doesn't fit.

## Changed rules
- **Tables** (`components/tables.md`): a table always sits on a card with 16px corners and 32px padding, never directly on a page ground. On a Plaster card the first row is Canvas; on a Canvas card it is Plaster. Rows are square, and the table is no longer clipped to a rounded edge.
- **Comparison and progress bars** (`rules/data-viz.md`): fully rounded at both ends (`--radius-pill`), with a Canvas pill track. Previously only one end was rounded.
- **Type scale ceiling** (`tokens/docs/typography.md`, `docs/design-reference.md`): above Text-8x, only the static display tiers exist, for static layouts only. The note that Text-16x was retired is removed.

## Consumers
- **Squarespace, Webflow and Rails:** update table styles and any comparison or progress bars. Use the Iron primary where a section serves two audiences.
- **Figma:** the display tiers exist as text styles 12, 16, 24, 32 and 48. Presentation and print files should use them instead of local sizes.
- **Regenerate tokens:** `tokens/generated/tokens.css` and `tailwind-theme.js` carry the five new tiers.
