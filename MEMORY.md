# Strategic Decisions

- **Timeline Acceleration:** Phase I (BDS) and Phase II (Website Execution) are overlapping. The BDS is acting as a living document to support immediate Squarespace website execution by Fraser.
- **Typography:** Sentence-case is an absolute, non-negotiable rule across all UI and marketing materials, including blog titles.
- **Blog Architecture:** Relying on native, clean Squarespace layouts (horizontal stacks/grids) with brand typography and photography rather than custom code hacks.
